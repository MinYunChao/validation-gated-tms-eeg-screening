Validation-Gated TMS-EEG Screening

A subject-exclusive pipeline that keeps waveform learning clean and admits auxiliary evidence only at the decision level when validation data support it.

Read the paper View code
Research use only. This release is not a medical device and does not support standalone diagnosis, treatment selection, or clinical deployment.

Design

Waveform first, auxiliary evidence under validation control

01

Subject-exclusive protocol

Every epoch from one subject remains in exactly one partition. Model selection, thresholds, residual strength, and gating rules use training and validation subjects only.

02

Clean waveform backbone

A spatio-temporal graph network operates on aligned waveform patches without subject-identity normalization or record-level clinical inputs.

03

Decision-level evidence

Covariance and non-diagnostic baseline evidence remain separate from waveform features and can alter a decision only through a validation-selected policy.

Internal evidence

Results are reported with their uncertainty

The fixed split explains decision changes; nested evaluation tests whether those changes persist across partitions. Neither is external validation.

Public release

Runnable code without participant data

Included

  • Installable Python package and command-line interface
  • Synthetic data generator and CPU smoke test
  • Leakage checks, subject aggregation, metrics, and bootstrap tools
  • Aggregate manuscript results and model documentation

Deliberately excluded

  • Human-participant recordings and clinical tables
  • Identifiers, split manifests, and individual predictions
  • Historical checkpoints and optimizer states
  • Names, emails, affiliations, funding, and local paths
